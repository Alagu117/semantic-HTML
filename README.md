# Semantic HTML5 & Accessible Component Architecture

## Project Name
Enterprise Dashboard

## Description
This project demonstrates a semantic HTML5 website with accessible components.

## Pages
- index.html – Home page
- dashboard.html – Dashboard page
- form.html – Accessible employee registration form

## Accessibility Features
- Semantic HTML5 tags (header, nav, main, section, article, aside, footer)
- Labels for form fields
- Fieldset and legend
- ARIA labels
- Keyboard-friendly structure
